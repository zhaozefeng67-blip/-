# PBSG Stage 2 结果

2026-11-24。108 个 run（3 个数据集 × 3 个 seed = 42/43/44），BNBU HPC 的 4090 单卡，max 30 epoch，patience 5。

## 0. 口径

- 划分：按原始时间轴先切 60/20/20，再在各 split 内部生成 12→12 滑窗，窗口不跨边界。
- 指标：在反归一化后的 flow 单位上计算；MAPE 分母阈值 1.0；H3/H6/H12 是各 horizon 的 MAE。
- 骨干：GWN-style，channels 32，dilations (1,2,4,4)，感受野 12，约 31k 参数；打分统一 $s_{ij}=\mathrm{ReLU}(e_i^\top e_j)$，$d_{\mathrm{emb}}{=}16$，行 softmax，自环分数 0。
- 公平性：Global-TopK 的 $k$ 按 $\mathrm{round}(\overline{|C_i|})+m$ 对齐 PBSG 的平均出度（PEMS08 $k{=}28$、PEMS04 $k{=}16$、PEMS07 $k{=}12$），不是 $K+m$。
- 每格 MAE 是 3 个 seed 的均值 ± 标准差。行序固定为 A–G，方便跨数据集对照。

邻接存储按各方法**实际使用的格式**估：Dense-Adaptive 是 $N^2\times4$ B 的稠密矩阵，稀疏方法按每条边 20 B（两个 int64 索引加一个 float32 权重）。存储优势随 $N$ 放大：PEMS08 只省 1.2 倍（$170^2$ 本来就小），PEMS04 省 3.6 倍，PEMS07 省 13.9 倍。墙钟方向相反：$N{=}883$ 上边数少 68 倍，s/epoch 反而慢 68%，因为稀疏 kernel 在这个规模不如 dense，构图只占每 epoch 的 1.4–7.8%。

## 4. 假设判定

| 假设                    | 判定         | 依据                                                      |
| :---------------------- | :----------- | :-------------------------------------------------------- |
| H1 受限候选降低构图成本 | 部分成立     | 边数/存储成立；墙钟不成立（见 §3）                        |
| H2 学边权优于固定权重   | 成立         | 三数据集 $\Delta$MAE 为 $-0.73/-0.92/-0.96$               |
| H3 预算边弥补先验缺口   | 条件成立     | 收益随 $\overline{|C_i|}$ 变弱而增大：$+0.03/-1.05/-1.28$ |
| H4 $m$ 边际收益递减     | 成立         | PEMS07 拐点在 $m{\approx}2$，之后回退                     |
| H5 构图成本随 $N$ 线性  | 成立（机制） | 每千条候选边 31–36 µs，三个 $N$ 一致                      |

## 5. 必须直说的一条

PBSG 在精度上没有稳定赢过 Global-TopK。同出度对齐后：

| 数据集 | C Global-TopK | 最好 PBSG | 差值   |
| :----- | ------------: | --------: | -----: |
| PEMS08 |        17.842 |    17.907 | +0.065 |
| PEMS04 |        22.036 |    21.917 | -0.119 |
| PEMS07 |        24.101 |    24.190 | +0.089 |

可辩护的优势只剩**边数与邻接存储**，以及 §4 里那条结构性诊断：预算边补的是先验支撑的表达力缺口。若要主张精度优势，得换更大的 $N$（Stage 3）或改候选排序（用道路距离）。
